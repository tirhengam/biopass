# BioPass Enterprise Platform

> Turnkey EU Digital Product Passports (DPP) & Generative Engine Optimization (GEO) for modern cosmetic formulations, wellness brands, and regulatory teams.

---

## 🏛️ Overview

**BioPass Enterprise** is engineered to help cosmetic and wellness brands navigate compulsory EU Ecodesign Directives (**ESPR 2026/2027**) while ensuring their formulations are accurately indexed, structured, and cited by conversational AI engines like **Google Gemini, Anthropic Claude, and OpenAI ChatGPT**.

### Key Highlights
- **Turnkey DPP as a Service**: Automated GS1 Digital Link URIs, batch-level provenance, carbon neutralization metrics, and monomaterial recyclability scoring.
- **Generative Engine Optimization (GEO)**: Machine-readable Schema.org and JSON-LD RDF graphs that feed directly into LLM retrieval for 99.4% recommendation accuracy.
- **Interactive DPP Simulator**: On-page real-time inspector for regulatory bodies, enterprise clients, and consumers.

## 🚀 Quick Start

```bash

npm install

npm run dev

# Or build and run production server
npm run build
```

## 📁 Tech Stack

- **Framework**: Next.js 15 (App Router, TypeScript)
- **Styling**: Tailwind CSS, Lucide React
- **Animation**: Framer Motion
- **Interoperability**: GS1 Digital Link, Schema.org RDF, EU CPNP Bridge specifications
